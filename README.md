## 🚀 Featured Projects

### 🏥 Comorbidity-Aware Multi-Disease Prediction
**Graph-Based Multimodal Fusion with Explainable AI** &nbsp;|&nbsp; *In progress*

Patients often have several related conditions at once, but most models predict one disease at a time. This project fuses **EHR data, lab results, vitals, and clinical notes** into a patient graph to predict multiple diseases together while capturing how they relate.

- Graph-based multimodal data fusion (GNN)
- Multi-disease prediction that accounts for comorbidities
- Explainable predictions using **SHAP** and **LIME**
- Recommendation engine and AI-assisted follow-up suggestions
- Clinical dashboard for viewing results

**Tech:** `Python` `PyTorch` `GNN` `FastAPI` `React` `SHAP` `LIME` `SQLite`
🔗 [View Repository](https://github.com/AzhaguMeenaG/multidisease-prediction)
